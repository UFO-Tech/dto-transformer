# 1.2 — union-типи, `#[AttrAssertions]` справді перевіряється

Теги: 1.2.0, 1.2.1, 1.2.2, 1.2.3. Перший реліз: 2025-07-13.

## Головне

- **Властивості й параметри з union-типом**: масив зіставляється з кожним класом union-а.
- **`#[AttrAssertions]` перевіряється**: помилка валідації у `fromArray()` тепер кидає `BadParamException` (раніше ковталась).
- Масив, що не підходить до властивості з типом-класом, кидає виняток замість того, щоб пройти як є.

## Що нового

### Union-типи (1.2.0)

Для union-типу масив пробується з кожним класом. Клас обирається, лише якщо в масиві є всі його обов'язкові параметри конструктора або ключі неініціалізованих властивостей. Якщо жоден клас не підійшов, а union містить `array`, лишається сирий масив; інакше кидається `BadParamException("Cannot assign array to property X::$p of type T")`.

```php
class ItemDTO
{
    public function __construct(public UserDto|DummyDTO $friend) {}
}

DTOTransformer::fromArray(ItemDTO::class, ['friend' => [/* ключі UserDto або DummyDTO */]]);
```

Нові protected-методи в `DTOTransformer`: `resolveValueForType()`, `tryTransformToMatchingClass()`, `doesArrayMatchClass()`, `constructorParamsMatch()`, `propertiesMatch()`, `isKeyMissing()`, `createUninitializedInstance()`.

## Зміни та виправлення

- **1.2.0**: помилки атрибутів більше не ковтаються — ігнорується лише `\ValueError` (непідтримуваний атрибут), тож помилки `AttrAssertions` і `AttrDTO` доходять до викликача як `BadParamException`. У 1.2.0–1.2.2 застосовується лише перший підтримуваний атрибут члена.
- **1.2.0**: значення за замовчуванням для відсутнього ключа більше не падає на класі без конструктора.
- **1.2.1**: `typeDescriptionToJsonSchema()` ставить `classFQCN` рівним самому типу, коли його немає в `$classes`, але клас існує.
- **1.2.2**: властивість з типом просто `array` знову приймає масив як є — у 1.2.0 і 1.2.1 вона кидала `BadParamException`. Член `array` в union-і лише дозволяє сирий масив і більше не пробується як кандидат.
- **1.2.3**: знову застосовуються всі атрибути члена по черзі; результат і далі проходить через розв'язання union-а / класу.

## Примітки до оновлення

1. **Помилки валідації тепер кидаються.** Порушення `#[AttrAssertions]` у `fromArray()` дають `BadParamException`; до 1.1.1 включно вони ігнорувались.
2. **Масиви, що не підходять до властивості з типом-класом, кидають** `BadParamException` замість того, щоб пройти як є.
3. Беріть 1.2.2+ для DTO з властивостями просто `array` і 1.2.3+ для членів з кількома атрибутами.
