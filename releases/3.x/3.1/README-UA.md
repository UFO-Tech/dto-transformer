# 3.1 — Symfony 8, PHP 8.4

Теги: 3.1.0. Перший реліз: 2026-09-25.

## Головне

- `symfony/serializer` і `symfony/validator`: `^7.2|^8.0` (було `^7.2`).
- PHP `>=8.4` (було `>=8.3`).

Змін у коді немає. Додано тести для DocBlock-типів `list<Dto>`, `non-empty-list<Dto>` і `list<string>`, які вже працювали.

## Примітки до оновлення

1. **Потрібен PHP 8.4.**
